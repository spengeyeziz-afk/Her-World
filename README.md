# Her World

Premium lifestyle simulation / virtual nightlife lounge for mobile.

Glamorous, cinematic experience. High-end nightlife meets luxury island resort.  
Store-safe · 17+ · Flirtatious adult themes, no explicit content.

## Play now

Open `index.html` in Chrome (or any modern browser). Keep the `img/` folder next to it.

### Features
- Cinematic title screen
- Multicultural cartoon-realistic avatar selection
- 6 themed lounges with full-body host art (Sofia, Mei, Amara, Luna, Isla)
- Tip · Champagne · Flirt · Emoji · Chat
- Token economy (200 start) + PayHere shop packages
